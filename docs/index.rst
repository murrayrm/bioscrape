################################################################################################
Bioscrape - Biological Stochastic Simulation of Single Cell Reactions and Parameter Estimation
################################################################################################

Bioscrape is a Python package, written in Cython for speed, for the
simulation and parameter estimation of chemical reaction network (CRN)
models, with a particular focus on stochastic, single-cell simulation
of synthetic and systems biology circuits.  Bioscrape reads models
from the Systems Biology Markup Language (SBML) and supports
deterministic, stochastic, and delayed/volume-aware simulation, as
well as Bayesian parameter inference from experimental data.

.. rubric:: Features

- Deterministic (ODE) and stochastic (Gillespie SSA) simulation of SBML models
- Support for delayed reactions and volume/lineage-aware simulation of
  dividing cells
- Bayesian parameter inference (MCMC) from bulk, flow cytometry, or
  single-cell trajectory data, with built-in and customizable priors
- Local sensitivity analysis of model trajectories with respect to parameters
- Compatible with models generated by `BioCRNpyler
  <https://biocrnpyler.readthedocs.io/en/latest/>`_, which can compile
  high-level circuit specifications down to SBML and simulate them via
  bioscrape
